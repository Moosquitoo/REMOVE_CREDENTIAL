Nettoyeur vidéo

Retirez les Content Credentials de vos vidéos

Supprime le manifeste C2PA, les métadonnées Adobe (XMP) et les autres informations de fichier, sans réencoder la vidéo. La qualité est identique.

    Tout se passe dans votre navigateur : aucune vidéo n'est envoyée sur un serveur.

    Ce qui est retiré
    • Le manifeste C2PA / Content Credentials (outil utilisé, mentions d'IA générative, historique)
    • Les métadonnées XMP d'Adobe et les blocs udta / meta
    • Les dates de création et le nom de l'encodeur

    Seules les métadonnées du fichier sont touchées. Un éventuel filigrane invisible intégré dans l'image elle-même n'est pas modifié. Formats fragmentés (streaming) non pris en charge.
